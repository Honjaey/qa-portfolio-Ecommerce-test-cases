# Bug Report 003

## Title
"Add to Cart" button unresponsive on mobile view

## Bug ID
BUG-003

## Severity
🔴 High

## Priority
High

## Environment
- Browser: Chrome (DevTools – Mobile Emulation)
- Device: Mobile view (375px width)
- OS: Windows 10

## Steps to Reproduce
1. Open the e-commerce website
2. Open Chrome DevTools → Toggle device toolbar (mobile view)
3. Navigate to any product page
4. Click the **"Add to Cart"** button

## Expected Result
Product is added to the cart and cart count updates.

## Actual Result
Button does not respond – no action taken, no feedback shown.

## Impact
Mobile users are completely unable to add products to cart, blocking purchases.
