# Bug Report 001

## Title
Checkout allowed without login

## Bug ID
BUG-001

## Severity
🔴 High

## Priority
High

## Environment
- Browser: Chrome (latest)
- OS: Windows 10
- Device: Desktop

## Steps to Reproduce
1. Open the e-commerce website
2. Browse and add a product to cart
3. Click the **Checkout** button without logging in

## Expected Result
User should be prompted to log in or create an account before proceeding to checkout.

## Actual Result
User proceeds directly to the checkout page without any login prompt.

## Impact
Allows unauthorized checkout flow, potentially causing order failures or data issues.
