# Test Plan – E-commerce Website

## 1. Objective
To verify that key features of the e-commerce application function correctly across desktop and mobile environments.

## 2. Scope

### In Scope
- User Login / Authentication
- Product browsing and selection
- Add to Cart functionality
- Checkout process

### Out of Scope
- Payment gateway processing
- Backend/API testing
- Performance/load testing

## 3. Test Types
| Type | Description |
|------|-------------|
| Functional Testing | Verify features work as specified |
| Regression Testing | Ensure new changes don't break existing features |
| UI Testing | Validate layout and responsiveness |
| UAT | Simulate real user behavior |

## 4. Tools
- **Browser:** Google Chrome (latest)
- **DevTools:** For mobile emulation
- **Test Cases:** Microsoft Excel
- **Bug Reports:** Markdown

## 5. Test Environment
- OS: Windows 10
- Browser: Chrome
- Screen sizes: Desktop (1920x1080), Mobile (375px)

## 6. Entry Criteria
- Application is accessible and stable
- Test cases have been reviewed and approved
- Test data is prepared

## 7. Exit Criteria
- All test cases have been executed
- All High/Critical bugs are resolved or deferred with approval
- Test summary report is complete

## 8. Risks
| Risk | Mitigation |
|------|------------|
| Unstable test environment | Test on a staging environment |
| Incomplete requirements | Clarify with product owner before testing |

## 9. Deliverables
- Test Cases (Excel)
- Bug Reports (Markdown)
- Test Summary (README)
- Screenshots (Evidence)
