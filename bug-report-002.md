# Bug Report 002

## Title
Broken link on homepage – "Shop Now" returns 404

## Bug ID
BUG-002

## Severity
🟡 Medium

## Priority
Medium

## Environment
- Browser: Chrome (latest)
- OS: Windows 10
- Device: Desktop

## Steps to Reproduce
1. Open the e-commerce homepage
2. Locate the **"Shop Now"** button/link
3. Click on it

## Expected Result
User is redirected to the products/catalog page.

## Actual Result
Page shows **404 – Page Not Found** error.

## Impact
Prevents users from browsing products via the main CTA, hurting conversion rate.
